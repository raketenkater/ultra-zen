# Contributing

Thanks for your interest in ultra-zen!

## Quick Start

```bash
git clone https://github.com/raketenkater/ultra-zen
cd ultra-zen
make build
```

## Pull Requests

1. Fork the repo and create a feature branch.
2. Run `make test` and `make vet` before submitting.
3. Keep changes focused — one feature per PR.
4. Write clear commit messages.

## Reporting Issues

Open a GitHub issue with:
- What you were trying to do
- What happened vs. what you expected
- The full output of `ultra-zen --version` and any relevant logs
